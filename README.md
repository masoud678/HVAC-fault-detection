##### \# HVAC Fault Detection

##### 

##### A step-by-step HVAC Fault Detection and Diagnostics (FDD) project built with Python.

##### 

##### \## Project Goal

##### 

##### The goal of this project is to demonstrate how a simple HVAC temperature rule can gradually evolve into a more advanced Fault Detection and Diagnostics system.

##### 

##### The project starts with basic Python logic and will progressively incorporate multiple HVAC data points, fault classification, trend analysis, and AI-assisted diagnostics.

##### 

##### \## Project Evolution

##### 

##### \### Step 1 — Basic Temperature Monitoring

##### \- Monitor Supply Air Temperature

##### \- Define a Supply Air Temperature Setpoint

##### \- Calculate temperature difference

##### 

##### \### Step 2 — Fault Detection

##### \- Detect abnormal temperature deviation

##### \- Classify system status as Normal, Warning, or Fault

##### 

##### \### Step 3 — Multi-Sensor Logic

##### \- Add Outdoor Air Temperature

##### \- Add Cooling Command

##### \- Combine multiple conditions for fault detection

##### 

##### \### Future Development

##### 

##### \- Fault diagnosis

##### \- Multiple HVAC sensors

##### \- CSV trend data

##### \- Trend analysis

##### \- Fault severity classification

##### \- FDD reports

##### \- Data-driven diagnostics

##### \- AI-assisted HVAC FDD

##### \- BAS / Building Automation integration

##### 

##### \## Current Status

##### 

##### The project currently implements rule-based HVAC fault detection using Supply Air Temperature, Setpoint, Outdoor Air Temperature, and Cooling Command.

#####

##### \## Project Philosophy

#####
